# Первый vertical slice

## Цель

Не делать «прототип интерфейса» или короткую линейную демку. Первый vertical slice должен доказать, что игра одновременно работает как:

- атмосферная графическая новелла;
- интерактивное расследование;
- история с убедительной Катериной;
- начало романтической динамики с Егором;
- система способностей с ценой;
- проект, который агент способен самостоятельно проходить и проверять.

## Объём

**Пролог + Глава 1 «След»**.

Ориентир — 25–40 минут первого человеческого прохождения без попытки увидеть все варианты. Точный хронометраж не является KPI; важнее законченная драматическая дуга.

# Содержание slice

## Сцена 1. Тату-студия, поздний вечер

Задачи:

- впервые показать Катерину;
- дать ей живой диалог с Еленой;
- показать повседневность до мистики;
- визуально закрепить татуировки и характер;
- дать игроку первый небольшой выбор позиции.

Интерактив:

- осмотреть незаконченный эскиз;
- коротко выбрать реакцию на замечание Елены;
- заметить повторяющийся элемент рисунка.

Визуальная цель:

Катерина должна выглядеть как полноценный главный персонаж, а не временный sprite. Уже здесь необходима первая согласованная версия её персонажного арта.

## Сцена 2. Ночная улица

Задачи:

- сменить ритм;
- создать ощущение Северина;
- показать, что игра умеет работать без постоянного dialogue box.

Интерактив:

- короткое исследование окружения;
- необязательные детали;
- реакция на оцепление/скорую.

## Сцена 3. Первый резонанс

Задачи:

- первый сильный визуальный момент игры;
- показать Печать Следа без объясняющего монолога;
- создать загадку.

Интерактив:

- игрок выбирает, прикоснуться ли к предмету/подойти ближе;
- после запуска Эха получает фрагментарный интерактивный эпизод;
- отдельные детали можно зафиксировать вниманием.

Визуальная цель:

Обычный рендер должен переходить в собственный язык Эха: изменение контраста/глубины, фрагментарные наложения, отдельное поведение линий печати, звук как часть восприятия.

## Сцена 4. Первая встреча с Егором

Задачи:

- сильный первый образ;
- немедленный конфликт, а не романтическая идеализация;
- продемонстрировать, что Егор понимает происходящее.

Катерина может:

- потребовать объяснений;
- скрыть, что именно увидела;
- саркастично отреагировать;
- отказаться уходить по его приказу.

Любой вариант остаётся характерным для Катерины.

## Сцена 5. Квартира Катерины

Задачи:

- эмоциональная пауза;
- показать одиночество без exposition;
- дать игроку взаимодействовать с личным пространством;
- закончить пролог изменением татуировки.

Интерактивные объекты могут раскрывать небольшие детали о ней, но не превращаться в обязательный pixel hunting.

## Сцена 6. Утро / Софья

Задачи:

- вернуть обычный мир;
- дать игроку решить, насколько Катерина делится странным опытом;
- показать, что скрытность имеет социальные последствия.

## Сцена 7. Возвращение к месту происшествия

Первое полноценное исследование сцены.

Минимум 5 интерактивных объектов:

- 2 обязательных;
- 2 необязательных;
- 1 ложный/контекстный след.

Игрок должен иметь возможность:

- осматривать без магии;
- использовать След на нескольких целях;
- получить разные объёмы информации;
- уйти, когда считает сцену достаточно исследованной.

## Сцена 8. Ночное заведение

Задачи:

- визуально расширить мир;
- снова встретить Егора;
- дать социальное расследование;
- проверить диалоги, улики и способности вместе.

Катерина может получить информацию минимум двумя способами: обычным разговором и магическим исследованием. Лучший результат требует комбинирования, а не обязательного спама магией.

## Сцена 9. Совместная находка

Катерина и Егор обнаруживают предмет с повреждённой печатью.

Игрок:

- выбирает, позволить ли Егору работать с находкой первым;
- может использовать След самостоятельно;
- получает первую настоящую конфликтующую интерпретацию одного события.

## Финал slice

Катерина сопоставляет символ на предмете со своим рисунком. Открывается первый простой экран доски расследования.

Финальная фраза/образ должен создавать желание продолжить не только ради Егора, но прежде всего ради ответа на вопрос о Катерине.

# Механики, которые обязаны работать в slice

1. диалоговый выбор позиции;
2. point-and-click исследование;
3. обнаружение и хранение улик;
4. Печать Следа;
5. strain как реальное последствие;
6. простейшая гипотеза на доске расследования;
7. начальные состояния trust/boundaries с Егором;
8. save/load;
9. agent observe/actions/act;
10. screenshot checkpoints.

# Что сознательно не входит

- все семь печатей;
- полноценная система времени;
- множество вампирских фракций на экране;
- боевые мини-игры;
- полноценный Кровный Архив;
- сложный инвентарь;
- несколько романтических маршрутов;
- огромная карта города;
- процедурная генерация контента.

# Минимальный набор персонажных артов

## Катерина

Для slice нужны не десятки костюмов, а качественный базовый комплект:

- full/three-quarter body canonical outfit;
- нейтральная поза;
- раздражение/скепсис;
- лёгкая усмешка;
- тревога, которую она старается скрыть;
- боль/перегрузка от Эха;
- более уязвимое выражение для домашней сцены;
- отдельные крупные планы руки/плеча/фрагмента печати.

## Егор

- базовый full/three-quarter body;
- нейтральный контроль;
- сухая усмешка;
- настороженность;
- момент сверхъестественной опасности;
- редкое искреннее беспокойство.

# Минимальные локации

1. тату-студия — вечер;
2. ночная улица/двор;
3. квартира Катерины — ночь/утро;
4. место происшествия — день;
5. ночное заведение;
6. короткий абстрактный слой Эха.

Качество важнее количества. Лучше шесть хорошо проработанных пространств с вариантами света и кадрирования, чем двадцать статичных случайных фонов.

# Аудио

Vertical slice должен иметь:

- собственную музыкальную тему Катерины;
- отдельный мотив сверхъестественного/Эха;
- тему или звуковой мотив Егора без чрезмерно романтического маркирования первой встречи;
- ambience для ключевых локаций;
- звуковой язык активации печати.

# Проверяемые сюжетные ветки

Минимум:

### A. Осторожная Катерина
Мало рассказывает Софье, не доверяет Егору, использует магию только при необходимости.

### B. Рисковая Катерина
Активно использует След, сильнее перегружает себя, быстрее получает часть информации.

### C. Открытая Катерина
Делится частью правды, допускает сотрудничество с Егором, но требует объяснений.

Все три пути должны закончить slice без hard lock и привести к общей центральной разгадке главы разными эмоциональными маршрутами.

# Acceptance criteria

Vertical slice считается успешным, если:

- Катерина узнаваема как конкретный персонаж уже после первых 10 минут;
- первая встреча с Егором создаёт одновременно интерес и недоверие;
- хотя бы одна улика получается без магии и хотя бы одна — с помощью Следа;
- игрок самостоятельно делает минимум один вывод из двух улик;
- использование способности имеет заметную цену;
- минимум один ранний выбор меняет более позднюю реплику/доступное действие;
- отказ доверять Егору не ломает прохождение;
- UI расследования понятен без длинного tutorial текста;
- агент может пройти slice из чистого reset, используя только player-visible observation;
- полный action trace воспроизводится;
- одинаковый seed и действия дают одинаковый логический результат;
- ключевые screenshots визуально соответствуют утверждённому направлению;
- в релизной ветке нет placeholder art, который можно принять за финальный asset.

# Следующий шаг после foundation

До написания полного сценария главы необходимо сделать **сценарно-механический beat sheet пролога**, где каждая сцена будет описана одновременно в четырёх слоях:

1. драматическая цель;
2. player action;
3. изменение game state;
4. необходимый визуальный/аудио asset.

После утверждения beat sheet начинается технический bootstrap и производство vertical slice.
