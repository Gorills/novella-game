# Зафиксировано

## Формат и жанр

- романтическая визуальная/narrative game;
- детектив и расследование являются настоящей игровой частью;
- вампиры, магия и способности существуют;
- графическое качество и выразительная режиссура обязательны;
- проект проходим агентом через то же game core, что human UI.

## Катерина

- 21 год;
- главная героиня;
- **тёмно-красное каре**;
- карие глаза;
- светлая кожа;
- множество татуировок на руках, плечах, спине и ногах;
- чёрная современная готическая одежда;
- серебряные украшения;
- независимая, упрямая, смелая, саркастичная;
- не любит показывать слабость;
- внутри добрая и одинокая;
- всю жизнь чувствовала себя чужой и хочет понять почему.

### Visual lock

`web/assets/katerina.webp` — единственный исходный источник истины по внешности Катерины.

Он имеет приоритет над старыми текстами и сгенерированными изображениями. **Каре обязательно. Предыдущее решение о длинных волосах отменено и считается ошибочным.**

Нельзя генерировать новую Катерину вместо locked reference без прямого запроса пользователя.

## Егор

- основной романтический персонаж;
- возраст неизвестен Катерине в начале;
- тёмные волосы;
- голубые глаза;
- бледная кожа;
- вампир;
- отношения строятся на доверии, границах и раскрытии скрытой информации, а не на одном love score.

## Магия

- татуировки Катерины содержат магические печати;
- не каждая татуировка является печатью;
- семь базовых узлов встроены в общий рисунок;
- способности помогают расследовать, но не выдают абсолютную истину;
- применение силы имеет физическую, психическую и сюжетную цену.

## Сюжетные принципы

- Катерина остаётся субъектом ключевых решений;
- Егор не становится постоянным спасителем;
- романтика не обязательна для центрального расследования;
- ошибочная гипотеза чаще ведёт к fail-forward;
- крупные повороты подготавливаются уликами;
- правила магии нельзя менять ради удобной развязки.

## Production principles

- «Готово» означает прохождение `docs/03-production/QUALITY_GATE.md`;
- заметные UI/арт-изменения нельзя принимать без реального рендера и просмотра screenshots;
- agent playthrough использует тот же game core;
- если пользователь разрешил merge и ждёт результат в `main`, готовую работу нельзя оставлять только в branch/PR.

# Рабочие решения до script lock

- финальное название игры;
- название города «Северин»;
- детали публичной личности Владлена Орлова при сохранении функции антагониста;
- точная профессия Катерины как тату-мастера/иллюстратора;
- названия вампирских групп и отдельных печатей;
- точное число глав;
- окончательный engine choice после проверки vertical slice.

# Не раскрывать игроку преждевременно

Agent observation не должен автоматически иметь доступ к:

- истинной цели антагониста;
- полной функции седьмой печати;
- прошлой связи Егора с историей Катерины;
- скрытым relationship values;
- истинной причине ложных улик;
- секретам, которых Катерина ещё не раскрыла.
